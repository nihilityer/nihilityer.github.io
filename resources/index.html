“免费下载”不等于“随意使用”

itch.io、Freesound、GitHub 等平台由作者自行选择许可。同一个站点里的两个资源可能分别要求署名、禁止商用或禁止再分发。下载时应保存资源页面、作者、版本和许可文件。

重点推荐：Koboyo Icons

Koboyo Icons 当前提供 71,262 个高质量手绘 SVG 图标，支持搜索、改色、缩放、裁剪和动画处理。

  • 个人和商业用途免费。
  • 无需注册、无需署名，没有席位或单项目费用。
  • 可以嵌入游戏、网站、应用、视频、文档和客户项目。
  • 可以修改图标并作为更大作品的一部分发布。
  • 不能把全部或大量图标重新包装成图标库、素材包或竞品，也不能让用户从你的产品中批量提取图标。

使用前可查看 Koboyo Icons License。

itch.io 免费游戏素材

itch.io Free Game Assets 是最适合独立游戏开发者浏览长尾素材的入口之一。除了完整素材包，还能找到针对 Godot、Unity、RPG Maker 等引擎或特定美术风格的小型资源。

itch.io 许可检查

“Free”只表示当前可以零价格下载，不自动代表 CC0、允许商用或无需署名。优先选择页面明确写有 CC0、CC BY、MIT、OFL 等许可的资源；只有“free to use”但没有完整条款时，商用前联系作者确认。

通用资产包：Kenney

Kenney Assets 覆盖 UI、2D、像素画、3D、音效和常用游戏占位素材，适合原型制作，也能直接用于正式项目。

Kenney 官方说明资产页中的游戏资源采用 CC0：允许商业项目使用且不要求署名。下载包内通常附有许可文件，建议随项目一起保存。

3D、材质与环境

Poly Haven

Poly Haven 提供 CC0 的高质量 3D 模型、纹理 和 HDRI，适合写实环境、灯光参考和材质制作。资源通常分多档分辨率，导入前按项目目标平台选择尺寸。

ambientCG

ambientCG 以 CC0 PBR 材质为主，也提供 HDRI、模型和程序化材质文件。使用时注意贴图命名、色彩空间、法线方向和实际比例。

Adobe Mixamo

Mixamo 适合快速取得人形角色动作、自动绑定和动作预览。可以把结果用于游戏，但不应把下载的原始角色或动画文件作为独立素材包再次分发。Adobe 账号、可用地区和服务条款可能变化，正式发布前查看 Mixamo FAQ。

音效与音乐

Freesound

Freesound 的环境声、Foley 和现场录音覆盖面很广，但许可由文件决定。筛选时优先查看 CC0；使用 CC BY 文件必须按作者要求署名，带 CC BY-NC 的文件不要用于商业游戏。

itch.io 音频

免费音乐和免费音效适合寻找完整主题包或同一作者制作的统一风格素材。仍需逐个查看许可；尤其注意循环剪辑、商用、署名、直播和原声带单独发行是否被允许。

字体

Google Fonts 提供开源字体文件和明确的字体家族许可，适合 UI、字幕和宣传图。下载后把对应的 OFL.txt 或其他许可文件一起纳入项目。

从 itch.io 或其他素材站下载字体时，还要确认是否允许：

  • 嵌入游戏安装包与 Web 游戏；
  • 用于 Logo、商店页和宣传视频；
  • 字体子集化、转换格式或制作位图字体；
  • 商业发行和多平台发行。

Shader、VFX、插件与代码

  • Godot Shaders：Godot 社区 Shader 示例，注意 Godot 版本和每篇页面的许可。
  • itch.io Free Shaders：可按引擎和渲染风格寻找 Shader/VFX 包。
  • Godot Asset Library：编辑器插件、Demo、工具和模板；每个项目均显示自己的许可。
  • GitHub Game Development：只有仓库明确包含许可证时才能按其条款复用；公开可见不等于开源。

下载时记录什么

建议在项目中为第三方资源保留一份清单：

字段用途
资源名与作者制作署名和后续追溯
原始页面重新下载、查看更新与条款
下载日期与版本应对页面内容或许可变化
许可名称与许可文件判断商用、署名、修改和再分发权限
修改记录区分原始文件与项目内衍生版本
使用位置删除或替换资源时快速定位
