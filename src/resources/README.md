::: important itch.io 许可检查

## 通用资产包：Kenney

[Kenney Assets](https://kenney.nl/assets) 覆盖 UI、2D、像素画、3D、音效和常用游戏占位素材，适合原型制作，也能直接用于正式项目。

Kenney 官方说明资产页中的游戏资源采用 **CC0**：允许商业项目使用且不要求署名。下载包内通常附有许可文件，建议随项目一起保存。

## 3D、材质与环境

### Poly Haven

[Poly Haven](https://polyhaven.com/) 提供 CC0 的高质量 [3D 模型](https://polyhaven.com/models)、[纹理](https://polyhaven.com/textures) 和 [HDRI](https://polyhaven.com/hdris)，适合写实环境、灯光参考和材质制作。资源通常分多档分辨率，导入前按项目目标平台选择尺寸。

### ambientCG

[ambientCG](https://ambientcg.com/) 以 CC0 PBR 材质为主，也提供 HDRI、模型和程序化材质文件。使用时注意贴图命名、色彩空间、法线方向和实际比例。

### Adobe Mixamo

[Mixamo](https://www.mixamo.com/) 适合快速取得人形角色动作、自动绑定和动作预览。可以把结果用于游戏，但不应把下载的原始角色或动画文件作为独立素材包再次分发。Adobe 账号、可用地区和服务条款可能变化，正式发布前查看 [Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)。

## 音效与音乐

### Freesound

[Freesound](https://freesound.org/) 的环境声、Foley 和现场录音覆盖面很广，但许可由文件决定。筛选时优先查看 **CC0**；使用 **CC BY** 文件必须按作者要求署名，带 **CC BY-NC** 的文件不要用于商业游戏。

### itch.io 音频

[免费音乐](https://itch.io/game-assets/free/tag-music)和[免费音效](https://itch.io/game-assets/free/tag-sound-effects)适合寻找完整主题包或同一作者制作的统一风格素材。仍需逐个查看许可；尤其注意循环剪辑、商用、署名、直播和原声带单独发行是否被允许。

## 字体

[Google Fonts](https://fonts.google.com/) 提供开源字体文件和明确的字体家族许可，适合 UI、字幕和宣传图。下载后把对应的 `OFL.txt` 或其他许可文件一起纳入项目。

从 itch.io 或其他素材站下载字体时，还要确认是否允许：

- 嵌入游戏安装包与 Web 游戏；
- 用于 Logo、商店页和宣传视频；
- 字体子集化、转换格式或制作位图字体；
- 商业发行和多平台发行。

## Shader、VFX、插件与代码

- [Godot Shaders](https://godotshaders.com/)：Godot 社区 Shader 示例，注意 Godot 版本和每篇页面的许可。
- [itch.io Free Shaders](https://itch.io/game-assets/free/tag-shaders)：可按引擎和渲染风格寻找 Shader/VFX 包。
- [Godot Asset Library](https://godotengine.org/asset-library/asset)：编辑器插件、Demo、工具和模板；每个项目均显示自己的许可。
- [GitHub Game Development](https://github.com/topics/game-development)：只有仓库明确包含许可证时才能按其条款复用；公开可见不等于开源。

## 下载时记录什么

建议在项目中为第三方资源保留一份清单：

| 字段 | 用途 |
| --- | --- |
| 资源名与作者 | 制作署名和后续追溯 |
| 原始页面 | 重新下载、查看更新与条款 |
| 下载日期与版本 | 应对页面内容或许可变化 |
| 许可名称与许可文件 | 判断商用、署名、修改和再分发权限 |
| 修改记录 | 区分原始文件与项目内衍生版本 |
| 使用位置 | 删除或替换资源时快速定位 |

::: tip 核验状态
Koboyo 与 Kenney 的许可说明最后核验于 **2026-08-03**。其他平台可能随时间调整服务或资源入口，具体作品始终以下载时附带的许可为准。
:::

需要引擎、DCC、发行平台等官方文档时，前往[官方文档与学习](./official-docs.md)。
