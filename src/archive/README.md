# 资料归档

这里完整保留项目原有资料。归档内容不代表当前推荐，其中部分工具、链接、模型能力和版本结论可能已经变化；当前选型请优先阅读[AI 工具推荐](/tools/)，经过复核的长期方法则收录在[技术分享](/tech/)。

## 原有内容入口

- [参考资料](/reference/)：AI 实验、游戏工具、算法、动画、框架和各类案例记录。

## 使用归档内容的建议

1. 把具体工具名和产品能力视为线索，通过官方页面确认它今天是否仍存在。
2. 区分可迁移的方法与绑定旧版本的操作步骤；算法思路、制作经验通常比界面截图更耐久。
3. 涉及价格、许可、商用权、平台支持或隐私时，不以归档内容作为最终依据。
4. 如果某篇内容经过重新核验并具有长期价值，会提炼到[技术分享](/tech/)并保留返回原始记录的链接。
