# 流场寻路

当大量单位前往同一个目标时，流场寻路可以让它们共享一次路径计算的结果。它常见于 RTS、塔防、群体移动和大规模敌潮；少量单位各自去往不同目标时，A* 往往更直接。

## 基本过程

1. 把可移动空间离散成网格，并记录每格的通行成本。
2. 从目标反向扩散，计算每格到目标的累计成本。
3. 每格指向相邻格中累计成本最低的方向，形成向量场。
4. 单位查询当前位置的方向并结合局部避障移动。

流场负责“整体往哪走”，并不自动解决单位互相推挤、动态障碍、窄门拥堵和角色运动学。工程中通常还需要局部避障、流场失效区域检测，以及目标或地图变化后的局部/分帧重算。

## 什么时候值得用

| 场景 | 建议 |
| --- | --- |
| 数百个单位共享一个或少数目标 | 很适合，路径计算可以复用 |
| 少量单位、目标各不相同 | 优先考虑 A* 或导航网格 |
| 地图和目标频繁变化 | 评估增量更新或分帧预算 |
| 需要精确绕开其他移动单位 | 流场之外再加入局部避障 |
