# AI 工具推荐

这不是穷举清单。主推荐只保留当前能力强、能够进入实际游戏制作工作流、并且仍在积极维护的工具。型号和结论最后核验于 **2026-08-02**。

## 推荐等级

- **首选**：当前优先试用，能力和完整工作流都较成熟。
- **备选**：在本地部署、成本、特定风格或软件生态上有独特优势。
- **观察**：技术前沿但稳定性、授权、可控性或接入成本暂不适合作为默认生产方案。

## 按工作类型选择

| 维度 | 当前首选 | 可直接完成程度 | 进入生产前还要做什么 |
| --- | --- | --- | --- |
| 代码开发 | [Codex](./code/) | 高：可在仓库内实现、测试、审查和修复 | 人工检查改动，在真实引擎与目标平台运行 |
| 2D/概念/UI/纹理 | [GPT Image 2](./assets/#gpt-image-2) | 中高：可生成与编辑最终候选资产 | 风格统一、拆层、尺寸/透明通道、授权复核 |
| 3D 模型 | [Meshy 6](./assets/#meshy-6) | 中高：可输出带纹理模型并继续绑定 | 检查拓扑、UV、材质、比例、碰撞与性能 |
| 2D Sprite 动画 | [Ludo Sprite Generator](./media/#ludo-sprite-generator) | 高：直接生成/编辑 Sprite Sheet、逐帧图和 JSON | 检查轮廓漂移、锚点、循环、像素网格和碰撞帧 |
| 2D 角色视频动画 | [Wan 2.2 Animate](./media/#wan-22-animate) | 中高：参考图角色复刻视频中的动作与表情 | 输出是视频帧，不是可控骨骼；需抠图、抽帧和一致性检查 |
| 3D 骨骼动画 | [Cartwheel / Uthana](./media/#3d-动画) | 高：文本/视频到动作、绑定、重定向并导出 FBX/GLB | 清脚滑、接触点、Root Motion、循环和目标骨架映射 |
| 配音/音效/音乐 | [ElevenLabs](./media/#elevenlabs) | 中高：可直接生成语音、音效与音乐候选 | 响度、循环、混音、表演一致性和权利确认 |
| 视频生成 | [Seedance 2.0](./media/#seedance-20) | 高：原生多模态音视频生成与参考编辑 | 剪辑、长镜头连续性、权利核验和真实玩法标识 |
| 本地化 | [GPT-5.6 + 术语库](./language-runtime/#游戏文本本地化) | 高：长上下文初译、角色语气、术语/LQA 检查 | 母语终审、变量/标签保护、引擎内 UI 回归 |
| 动态 NPC/语音交互 | [GPT-Realtime-2.1](./language-runtime/#gpt-realtime-21) | 中高：实时语音、推理与受控工具调用 | 内容安全、延迟、成本、断网回退与剧情约束 |

## 我们如何避免推荐迅速过期

推荐页不写容易变化的固定价格；模型链接尽量指向官方当前页；明确记录核验日期；旧型号不再作为主推荐，但历史实验继续保存在[资料归档](/archive/)中。如果官方已将某型号标为 deprecated，主页面会迁移到后继型号。
